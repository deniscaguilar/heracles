# Protótipos (descartáveis)

Código da Etapa 0 (decisões e provas técnicas). **Não é código de produção** e não é referência de qualidade.

- Serve para responder uma pergunta e gerar um registro em `docs/stage-0/`. Depois disso pode ser apagado.
- Fica fora do build de produção, do portão de cobertura e da arquitetura em camadas.
- As regras de segurança continuam valendo: nenhum segredo, exame real, dado pessoal ou dado de terceiros no repositório. Isso vai só em `local/`, que o git ignora.
- Nada daqui é copiado para `backend/`, `mobile/` ou `web/` sem passar por spec, plano e revisão.

Pastas previstas: `sync/` (P1), `swap/` (P2), `exam-extraction/` (P3), `queues/` (P4), `health-devices/` (P6).

Spec e plano: `specs/platform/stage-0-proofs/`.
